# What is a root?
NOTE:
- 2x² - 3x + 1, with x = 1
END
Put x = 1 into 2x² – 3x + 1. What do you get? Hold that thought.
A quadratic is an equation where the highest power of x is 2.
NOTE: What is a root?
- ax² + bx + c = 0, with a ≠ 0
- a root is a number alpha with a × alpha² + b × alpha + c = 0
- a quadratic has at most two roots
END
Here is the key idea. A root is a value of x that makes the whole equation exactly zero. Let's check x = 1 one step at a time.
NOTE:
- 2 × 1² = 2
END
NOTE:
- 2 - 3 × 1 = 2 - 3 = -1
END
2 times 1 squared is 2.
Minus 3 times 1 is minus 3, so 2 minus 3 is minus 1.
NOTE:
- -1 + 1 = 0
END
Add 1, and we get 0. So 1 is a root. Think of a root as a key that fits the lock exactly. Clear so far?

# Splitting the middle term
Now, what if the numbers are harder? We split the middle term. Let's use x² + 5x + 6 = 0 as our example.
NOTE: Splitting the middle term
- x² + 5x + 6 = 0, so a × c = 1 × 6 = 6 and b = 5
- find two numbers: product a × c, sum b
END
Here is the first question. We need two numbers that multiply to 6 and add to 5. Which two?
Take a moment. Good, the numbers are 2 and 3.
NOTE:
- 2 × 3 = 6, and 2 + 3 = 5
END
Two times 3 is 6, and 2 plus 3 is 5. So we split the middle term, 5x, into 2x and 3x.
NOTE:
- x² + 2x + 3x + 6 = 0
END
Group the first two terms and the last two. Then take out the common factor.
NOTE:
- x(x + 2) + 3(x + 2) = 0
- (x + 3)(x + 2) = 0
END
Here are the six steps, in order.
FIGURE slide 3
First, we write the equation as ax² + bx + c = 0.
Second, we find two numbers whose product is a × c and whose sum is b.
Third, we split the middle term bx using those two numbers.
Fourth, we group the terms and take out the common factors.
Fifth, we write it as a product of two linear factors.
Sixth, we set each factor to zero and solve.
So x + 3 = 0 gives x = –3, and x + 2 = 0 gives x = –2.
NOTE:
- (-2)² = 4
END
Check x = –2 in the original equation. Its square is 4.
NOTE:
- 4 + 5 × (-2) + 6 = 4 - 10 + 6 = 0
END
So 4 minus 10 plus 6 is 0. Good. Why does this work? If two things multiply to zero, one of them must be zero. Takeaway: split the middle term, factorise, then set each factor to zero.

Here is the graph of y = 2x² – 5x + 3. Before I move the slider, where do you think the curve crosses the x-axis?

Here, at x = 0, y is 3. The curve crosses the y-axis there, so this is not a root.
NOTE:
- at x = 1.5: y = 2 × 2.25 - 5 × 1.5 + 3 = 4.5 - 7.5 + 3 = 0
END
Now, here at x = 1, y is 0. The graph sits right on the x-axis.
And here, at x = 1.5, y is also 0.
NOTE: Roots on the graph
- roots are where y = 0
- the graph meets the x-axis at x = 1 and x = 1.5
END
So the roots are 1 and 1.5, the same roots we get by factorising. Takeaway: a root is an x-value where the graph meets the x-axis. Clear so far?

# NCERT Example 3
Open your book at page 42.
NOTE:
- Example 3: 2x² - 5x + 3 = 0
END
This is Example 3: find the roots of 2x² – 5x + 3 = 0 by factorisation. Try it yourself first, then compare with me.
Here is the setup.
NOTE: Example 3 setup
- a × c = 2 × 3 = 6, and b = –5
- two numbers: product 6, sum –5
END
Which two numbers multiply to 6 and add to –5? Think about the signs.
Yes, –2 and –3. Their product is 6, and their sum is –5.
NOTE:
- split –5x as –2x – 3x
END
Now we rewrite the expression, one step at a time.
NOTE:
- 2x² – 2x – 3x + 3
END
Group the first two terms and the last two terms.
NOTE:
- 2x(x – 1) – 3(x – 1)
END
Take out the common factor x – 1.
NOTE:
- (2x – 3)(x – 1) = 0
END
So either 2x – 3 = 0 or x – 1 = 0. From 2x – 3 = 0, we get x = 3/2. From x – 1 = 0, we get x = 1. Be careful: 2x – 3 = 0 gives 3/2, not 2/3.
Now let's check. For x = 1, we work it out in steps.
NOTE:
- 2 × 1² - 5 × 1 + 3 = 2 - 5 + 3 = 0
END
So x = 1 gives 0, as it should.
Now x = 3/2.
NOTE:
- 2 × (3/2)² = 2 × 9/4 = 4.5
END
For x = 3/2: 2 times 9/4 is 4.5.
NOTE:
- 5 × 3/2 = 7.5
END
Minus 5 times 3/2, which is 7.5.
NOTE:
- 4.5 - 7.5 + 3 = 0
END
That is 4.5 minus 7.5 plus 3, which is 0.
Both roots check out: 1 and 3/2. That matches the book. Did you get the same?

# Recap
Let's bring it together. A root makes the equation zero. To factorise, we find two numbers with product a × c and sum b, split the middle term, group, and factorise. Then we set each factor to zero.
NOTE: Remember
- product = a × c, sum = b
- each factor set to zero gives one root
- check every root in the original equation
END
The roots are where the graph meets the x-axis. Back to our opening question: x = 1 is a root of 2x² – 3x + 1 = 0, because it gives zero.
