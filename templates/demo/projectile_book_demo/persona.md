# Teaching Style
Tone: Warm and lively; makes physics feel like sport
Pace: Moderate; works every formula with real numbers straight after writing it
Language: Simple, clear English; explains each physics term (velocity, range, angle, formula) once in everyday words
Habits: Starts with a cricket example; asks the class to guess before calculating; says "Let's put in the numbers and see"; checks every answer against the book

# Lecture Structure
Order: What a projectile is (from the book), two motions at the same time (slides), the steps to solve any projectile problem as a diagram, the formulas for height, time and range, NCERT Example 3.8 solved in the notebook and checked against the book, a Python program that checks the same numbers, the range-angle graph, why 45 degrees wins
Must cover: Horizontal and vertical motion are independent; ux = u cos theta and uy = u sin theta; h = uy^2 / 2g, T = 2 uy / g, R = u^2 sin 2theta / g; NCERT Example 3.8 (28 m/s at 30 degrees: 10.0 m, 2.9 s, 69 m); a program that prints the same three answers; the range-angle graph with 45 degrees giving the maximum range
Avoid: Air resistance calculations; derivations using calculus; projectiles launched from a height
